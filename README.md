# C Programming Practice & Assignments

Welcome to the C Programming repository! This repository contains structured practice codes, assignments, and classwork exercises focused on procedural programming and core problem-solving techniques in C.

## Topics Covered:
- Basic algorithmic strategy & selection techniques
- Iteration techniques and functional approaches
- Numbers, Digits, and Numbering systems
- Arrays, dynamic memory allocations, and matrix operations
- Bitwise operators and mask designing
- Structures, Unions, and design strategies
- Searching and sorting algorithms
- Recursion vs Iteration
- File handling and basic Data Structures (Linked Lists, Stacks, Queues)

## Structure:
- `Assignments/`: Organized assignment sets from Assignment_1 onwards.
- `Classwork/`: Daily practice sessions and code snippets.
